# SRC home-screen app

These files make the "SRC" icon on phones. They open the SRC app full screen.
Only one line needs changing: in `index.html`, put the Admin app link (ends in `/exec`) into `var APP_URL = '...'`.
Then host the folder on GitHub Pages (see SETUP.md, "Put the home-screen app online") and paste the page address into the app under Settings > App > Home-screen app address.
